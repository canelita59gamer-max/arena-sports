# Memory

Este archivo sirve como memoria de contexto del proyecto.

## Propósito
- Registrar decisiones importantes.
- Mantener notas de cambios y evolución del proyecto.
- Servir como referencia rápida para futuras sesiones.

## Uso recomendado
- Añadir resúmenes de acuerdos, problemas resueltos y próximos pasos.
- Mantenerlo actualizado tras cada cambio relevante.
