# Claude

Este archivo funciona como contexto técnico y operativo para Claude dentro del proyecto Arena Sports.

## Propósito
- Definir el entorno y objetivo del proyecto.
- Dar prioridad a la consistencia visual, funcional y deportiva del torneo.
- Mantener una guía clara para apoyar mejoras, correcciones y mantenimiento del sitio.

## Contexto del proyecto
- Proyecto web para Arena Sports.
- Sitio orientado a promocionar y administrar el torneo Faith Cup 2026.
- El contenido principal es la información del campeonato: equipos, partidos y goleadores.
- La página se compone principalmente de HTML, CSS y JavaScript vanilla.

## Prioridades de trabajo
1. Mantener la experiencia visual deportiva y moderna.
2. Respetar la estructura y diseño actual del sitio.
3. Revisar que los datos del torneo no queden inconsistentes.
4. Mejorar funcionalidad sin romper la lógica existente.
5. Mantener el contenido claro, profesional y fácil de administrar.

## Reglas de edición
- No inventar resultados, equipos ni jugadores si no forman parte del contexto real del torneo.
- Mantener el mismo estilo visual del sitio en todas las secciones.
- Priorizar claridad y legibilidad sobre elementos excesivamente complejos.
- Cuando se modifique la lógica del torneo, revisar que posiciones, partidos y goleadores sigan siendo coherentes entre sí.
- Si hay incertidumbre sobre un dato, consultar este archivo y la memoria del proyecto antes de asumirlo.

## Estructura importante
- La vista principal está en torneo.html.
- La lógica y comportamiento del sitio se gestionan con JavaScript.
- El archivo principal debe mantenerse claro y ordenado para facilitar futuras actualizaciones.

## Actitud recomendada para la ayuda
- Ser preciso y útil.
- Proponer soluciones funcionales y alineadas al estilo del proyecto.
- Mejorar la usabilidad del torneo sin complicar el flujo administrativo.
- Mantener un enfoque centrado en el usuario final y en la administración del certamen.

## Objetivo final
Ayudar a que el sitio de Arena Sports sea una herramienta moderna, visualmente sólida y operativamente útil para gestionar el torneo Faith Cup con claridad y profesionalismo.
