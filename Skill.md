# Skill

Este archivo documenta las habilidades o capacidades clave del proyecto o del flujo de trabajo.

## Propósito
- Describir competencias, funciones o procesos importantes.
- Servir como guía para entender cómo trabajar con el proyecto.
- Organizar conocimientos reutilizables.

## Uso recomendado
- Enumerar habilidades técnicas, flujos de trabajo o buenas prácticas.
- Actualizarlo cuando se agreguen nuevas capacidades o procesos.
