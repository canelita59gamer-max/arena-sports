# Arena Sports — Sitio Web Oficial

> "Donde el juego se vuelve historia."

## Estructura del proyecto

```
arena-sports/
│
├── index.html              ← Página principal (estructura HTML)
│
├── css/
│   └── styles.css          ← Todos los estilos visuales
│
├── js/
│   └── main.js             ← Animaciones e interacciones
│
├── assets/
│   ├── logos/              ← Logo Arena Sports (PNG, SVG)
│   └── images/             ← Fotos de eventos, equipos, etc.
│
└── README.md               ← Este archivo
```

## Cómo editar en VS Code

1. Abre la carpeta `arena-sports/` en VS Code (`File > Open Folder`)
2. Instala la extensión **Live Server** (Roger Gill) si no la tienes
3. Haz clic derecho sobre `index.html` → **Open with Live Server**
4. El sitio se abre en el navegador y se actualiza en tiempo real al guardar

## ¿Qué edita cada archivo?

| Archivo | Qué contiene | Cuándo tocarlo |
|---|---|---|
| `index.html` | Textos, secciones, estructura | Cambiar contenido, agregar secciones |
| `css/styles.css` | Colores, fuentes, espaciado | Cambiar diseño visual |
| `js/main.js` | Animaciones de scroll | Cambiar comportamiento |
| `assets/logos/` | Logo Arena Sports | Agregar versiones del logo |
| `assets/images/` | Fotos de eventos | Agregar fotos reales |
