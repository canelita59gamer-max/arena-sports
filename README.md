# Arena Sports

Sitio web institucional para Arena Sports, una organización dedicada a la gestión y desarrollo de torneos y eventos deportivos.

## Contenido del proyecto
- Landing page con secciones de servicios, historial, agenda, patrocinadores y contacto.
- Diseño oscuro con estética deportiva y estilo moderno.
- Animaciones de aparición, menú móvil y formulario interactivo.

## Archivos principales
- index.html: estructura del contenido.
- css/styles.css: estilos visuales del sitio.
- js/main.js: interacciones, menú móvil y formulario.

## Uso
1. Abre el archivo index.html en tu navegador.
2. Si deseas servirlo localmente, puedes usar un servidor simple como Live Server o Python.
